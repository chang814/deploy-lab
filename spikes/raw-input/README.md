# P0-4 Spike：Godot 4 原始鼠标输入验证

要回答的问题：**Windows 下 Godot 4.7 在鼠标锁定模式（MOUSE_MODE_CAPTURED）收到的位移，是不是原始鼠标计数？** 也就是说，它是否不受 Windows 指针速度和「提高指针精确度」（鼠标加速）影响，且不丢失、不取整。

这是一个一次性的验证工程（spike），代码不直接进入正式游戏；`look_math.gd` 和它的测试会在 v0.1 里转正。

## 怎么运行

1. 打开 Godot 4.7.2 编辑器 → 导入 → 选择本目录的 `project.godot` → 按 F5 运行
2. 在左下角面板填入你鼠标的 **DPI** 和 **CS2 里的灵敏度**
3. 按 **C** 锁定鼠标开始测试，**Esc** 释放

单元测试（无界面）：

```powershell
<Godot 控制台版 exe> --headless --path spikes/raw-input -s res://tests/test_look_math.gd
```

## 界面上的关键读数

| 读数 | 含义 | 期望 |
|---|---|---|
| 累计 X / Y counts | `screen_relative` 的累加，视角按它转动 | 只随物理位移变化 |
| relative 路 | `relative` 的累加，作为对照 | 窗口不缩放时与上一行相同 |
| 非整数事件 | 出现小数位移的事件数 | **0**（出现小数说明被缩放过） |
| relative≠screen_relative 的事件 | 两路不一致的次数 | **0** |
| yaw（不回绕） | 累计转过的角度，向右为正 | — |

每测完一次，按 **L** 把当前读数追加到 CSV（路径显示在面板上），再按 **R** 清零。

## 测试步骤（需要人来做）

准备：一把尺子贴在鼠标垫边上，鼠标贴着尺子平移。每项做 **5 次**，每次结束都按 L 记录。

**T1 快慢一致**（最关键）
- 慢慢平移 10 cm，记录；再用很快的速度平移同样的 10 cm，记录
- 通过：快慢两组的中位数相差 < 1%。如果快的明显更多，说明有加速

**T2 不受 Windows 设置影响**
- 打开「设置 → 蓝牙和其他设备 → 鼠标 → 其他鼠标设置 → 指针选项」
- 依次在以下条件下重复 T1 的慢速 10 cm：
  - 指针速度拉到最慢
  - 指针速度拉到最快
  - 打开「提高指针精确度」
- 通过：各条件下的计数和默认设置相差 < 1%。测完**把设置恢复原样**

**T3 绝对精度**
- 理论值：10 cm ÷ 2.54 × DPI（800 DPI 时约 3149.6 counts）
- 通过：与理论值相差 < 5%。鼠标标称 DPI 本身有误差，所以这一项只做参考，主要看 T1、T2

**T4 窗口模式**
- 分别在窗口模式和全屏（按 F）下重复慢速 10 cm
- 通过：计数一致，「非整数事件」和「relative≠screen_relative」始终为 0

**T5 和 CS2 对照**（验证整条链路）
- 在 CS2 本地离线服务器中打开 `cl_showpos 1`（可以看到视角角度），对准一个标志物
- 鼠标贴着尺子平移固定距离（比如 20 cm），记下 CS2 视角转了多少度
- 在本工程中用同样的灵敏度和同样的 20 cm 平移，看 yaw 读数
- 通过：两边角度相差 < 1°（物理平移本身有误差，看多次的中位数）
- 也可以直接测：面板显示的「理论 cm/360°」，在两边各平移这么多，看是否都正好转回原来的标志物（本工程里是红色 0° 柱）
