# P0-4 Spike：Godot 4 原始鼠标输入验证

要回答的问题：**Windows 下 Godot 4.7 在鼠标锁定模式（MOUSE_MODE_CAPTURED）收到的位移，是否与 Windows 原始鼠标计数（Raw Input）逐轮完全一致？** 一致就说明它不受系统指针速度和「提高指针精确度」影响，也不丢失、不取整。

判断方法是**和独立基准对比**，不靠尺子：`tools/rawinput_counter.py` 直接向 Windows 注册 Raw Input，与 Godot 同时接收同一只鼠标的同一段移动。两边用同一次鼠标点击划分「轮」。**前提是点击时鼠标静止**：如果点击的同一个数据包里带有位移，Godot 那边的事件先后顺序未知，基准会把这一轮标为作废。

这是一次性的验证工程。`look_math.gd` 和它的测试会在 v0.1 转正。视角参数（m_yaw、m_pitch、pitch 上下限、基准 FOV）放在 `data/look_defaults.json`，不写在代码里。

## 准备

1. 打开 Godot 4.7.2 编辑器 → 导入 → 选择本目录的 `project.godot`
2. 在本目录打开一个终端，启动基准计数器（保持它开着）：
   ```powershell
   python -I tools/rawinput_counter.py --csv rawinput_runs.csv
   ```
3. 在 Godot 中按 F5 运行 spike。在左下角填入 **DPI**、**CS2 灵敏度**，以及本组的**备注**（如 `T1-慢`）
4. 按 **C** 锁定鼠标

## 一轮测量的固定流程

> **鼠标保持静止 → 按中键（两边同时清零，开始新一轮）→ 移动 → 停止移动 → 按右键（两边同时记录）**

- 点击时鼠标不要动。如果动了，基准会把本轮标为作废（`boundary_motion=1`）
- 两边的「轮号」应该一致。Godot 只在按中键时开新轮，不会单方面开新轮。如果轮号仍然对不上，重启两个程序，从头开始
- 一轮进行中如果**释放鼠标、窗口失焦或按 Z 回正视角**，Godot 会把本轮标为作废，面板会提示；按中键重开即可
- 改「备注」的顺序：先按右键记录完本轮 → Esc 释放 → 改备注 → C 锁定 → 中键开新轮
- **只有两边都标为有效（`valid=1`）的轮次才参与比较**
- 两边的记录文件：Godot 的路径显示在面板底部；基准的是本目录下的 `rawinput_runs.csv`

## 测试项

每项至少 **5 轮**。主判据是 **Godot 计数 = 基准计数**（X、Y 两轴）。

| 测试 | 做法 | 通过标准 |
|---|---|---|
| **T1 快慢** | 慢速平移约 10 cm，5 轮；快速甩动约 10 cm，5 轮；再做几轮画圈（两轴同时动） | 每轮两轴计数与基准**完全相等** |
| **T2 系统设置** | 在以下三种条件下**各做快、慢两组**：指针速度最慢、指针速度最快、打开「提高指针精确度」（设置 → 蓝牙和其他设备 → 鼠标 → 其他鼠标设置 → 指针选项）。**测完恢复原设置** | 每轮仍与基准完全相等 |
| **T3 窗口模式** | 窗口模式、全屏（F）各做 5 轮；再把 Windows「缩放」改为 125% 或 150% 各做 5 轮（测完恢复） | 每轮 `screen_relative` 与基准完全相等 |
| **T4 高速与高回报率** | 鼠标回报率设为你平时用的最高值（如 1000/2000/4000 Hz），用最快速度甩 5 轮 | 每轮与基准完全相等（检查高速时有无丢事件） |
| **T5 和 CS2 对照** | 见下文 | 角度差 < 1° |

**诊断项不是判据：** 面板上的「含小数」「两路不一致」只用来解释现象。`relative` 会受视口缩放影响而与 `screen_relative` 不同，这是正常的。真正的判据只有「与基准相等」。

**允许的误差：** 理想情况是 0。如果出现极小的偏差（如每轮差 1–2 counts），先看是否在点击边界发生了移动，重测确认。如果偏差稳定且随移动量增长（比如总是少 0.5%），则判为不通过。

**T1 的附加检查（不作判据）：** 用尺子量 10 cm 时，计数应约为 10 ÷ 2.54 × DPI（800 DPI 约 3150）。由于鼠标标称 DPI 本身有误差，这一项只用来发现明显的设置错误。

## T5：和 CS2 对照（验证整条链路）

用标柱做 360° 对照最可靠，因为不需要读角度：

1. 两边设置相同的灵敏度，面板会显示「cm/360°」
2. 在 CS2 本地离线服务器中对准一个明显的标志物，贴着尺子平移这个距离，看是否正好转回标志物；记下偏差（偏过了多少或差了多少）
3. 在 spike 中对准红色 0° 柱，做同样的平移，看是否回到 0° 柱
4. 两边的偏差方向和大小应该相近。因为都是同一次物理平移的误差，偏差应该同向

如需读数：CS2 的 `cl_showpos 1` 可以显示视角角度（**需现场确认当前版本可用**）。CS2 的角度显示在 -180°~180° 之间会回绕，比如从 179° 转到 -179° 实际是向右转了 2°，不是 -358°。这时只比较小角度（< 180°）的转动，或按「转过的整圈数 + 余数」计算。还要确认 CS2 中 `m_yaw` 是默认的 0.022。
