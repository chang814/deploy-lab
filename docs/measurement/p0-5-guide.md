# P0-5 手感测量：录制指引（给测试人）

目标：录下切枪、拔刀、检视的慢动作视频，Claude 逐帧分析出时长。**你只负责录**，分析由 Claude 来做。

预计时间：准备 10 分钟，录制 20–25 分钟。

> **红线**
> - 只在**本地离线服务器**（「开始游戏 › 练习」）里做，不要进任何官方匹配或社区服务器
> - **不往 CS2 目录里放任何文件**：所有设置都在控制台里粘贴命令完成
> - OBS 只用「**显示器采集**」，不要用「游戏采集」（游戏采集会注入游戏进程）
> - 录像只放在本地临时文件夹，不上传、不进仓库

## 本次范围（第一批）

这是第一批测量，只覆盖：步枪（AK-47）、手枪（Glock-18）、默认刀之间的切换，Q 快切，滚轮切换，刀的拔出、检视、轻击和重击。其他武器和刀型以后分批测。

手枪选 Glock 而不是 USP：USP 装着消音器，枪口火光很弱，不好判断第一枪。

## 一、准备（只做一次）

**1. CS2 设置**
- 设置 › 视频 › 显示模式：**全屏窗口化**（否则下面的输入显示层可能被挡住）
- 设置 › 视频 › 垂直同步：**关**
- 设置 › 游戏：启用**开发者控制台**

**2. OBS 设置**
- 来源：添加「**显示器采集**」
- 设置 › 视频 › 常用帧率：**60**
- 设置 › 输出 › 录像路径：`D:\TempFiles（临时文件）\mcs\p0-5\`
- 录完一段后，在 OBS 的「统计」面板看一眼「因编码/渲染延迟而跳过的帧」，**应为 0**；不为 0 就告诉 Claude

**3. 启动输入显示层**（屏幕左上角的小窗口，按键时对应格子会变绿）

在 `D:\桌面\mcs` 打开终端运行：

```powershell
python -I tools/input_overlay/input_overlay.py --csv "D:\TempFiles（临时文件）\mcs\p0-5\input_log.csv"
```

可以用鼠标拖动它的位置，确保它不挡住武器，但**一定要在录像画面里**。

**4. 进本地地图，粘贴设置命令**

开始游戏 › 练习 › 任选一张地图。打开控制台（`~` 键），把下面**一整行**粘贴进去，回车：

```
sv_cheats 1; bot_kick; mp_warmup_end; mp_freezetime 0; mp_roundtime_defuse 60; mp_roundtime 60; mp_buy_anywhere 1; mp_buytime 9999; mp_startmoney 60000; mp_maxmoney 60000; sv_infinite_ammo 1; mp_respawn_on_death_ct 1; mp_respawn_on_death_t 1; fps_max 0; cl_showfps 1; give weapon_ak47; give weapon_glock
```

**5. 确认设置生效**（任何一项不对就停下，把控制台截图发给 Claude）
- 控制台里**没有**红色或黄色的「Unknown command」「requires sv_cheats」之类的报错
- 关掉控制台，按 **1** 是 AK，按 **2** 是 Glock，按 **3** 是刀
- 再输入 `version`，**把版本号拍照或复制下来**

## 二、录制方法（每一项都一样）

1. 打开控制台，输入 `host_timescale 0.1` 回车，**关掉控制台**（控制台开着时按键会被控制台吃掉）
2. 随便走两步，确认进入了慢动作
3. OBS 开始录像
4. 按下面表格的「操作」做 **5 次**。每次之间**等武器完全静止**再做下一次（慢动作下一个动作可能要好几秒，不要着急）
5. OBS 停止录像，把文件**重命名成表格里的编号**（例如 `A.mkv`）
6. 全部录完后，在控制台输入 `host_timescale 1` 恢复

**左键要「提前」按住：** 需要开枪的项目，请在按切枪键**之后立刻**按住左键不放，直到第一枪打出来。慢动作下切枪要好几秒，你的左键一定早于「允许开火」的那一刻，第一枪就会在允许的瞬间打出来。输入显示层会把你按键的时刻也录下来，Claude 能核对。

## 三、要录的项目

| 编号 | 起始状态 | 操作（每次做完回到起始状态） | 测的是 |
|---|---|---|---|
| A | 拿刀 | 按 **1** → 立刻按住**左键**到第一枪打出 → 松开 → 按 **3** 回到刀 | 刀 → 步枪 |
| B | 拿 AK | 按 **2** → 按住左键到第一枪 → 松开 → 按 **1** 回到 AK | 步枪 → 手枪 |
| C | 拿 Glock | 按 **1** → 按住左键到第一枪 → 松开 → 按 **2** 回到 Glock | 手枪 → 步枪 |
| D | 拿 AK | 按 **3** → 按住左键（刀挥出）→ 松开 → 按 **1** 回到 AK | 步枪 → 刀，多久能挥刀 |
| E1 | 拿 Glock，先按 1 再按 2 一次（让「上一把」是 AK） | 按 **Q**（切到 AK）→ 按住左键到第一枪 → 松开 → 按 **2** 回到 Glock | Q 快切：手枪 → 步枪 |
| E2 | 拿 AK，先按 2 再按 1 一次（让「上一把」是 Glock） | 按 **Q**（切到 Glock）→ 按住左键到第一枪 → 松开 → 按 **1** 回到 AK | Q 快切：步枪 → 手枪 |
| W | 拿 AK | **滚轮往下滚一格**（切到下一把）→ 按住左键到第一枪 → 松开 → 按 **1** 回到 AK | 滚轮切换 |
| K1 | 拿 AK | 按 **3**，**什么都不按**，等刀完全拔出、停稳 → 按 **1** 回到 AK | 刀的完整拔出时长 |
| K2 | 拿刀，站着不动 | 按住**左键**不放，连续挥 5 下后松开（这一项只做 1 次即可） | 轻击间隔 |
| K3 | 拿刀，站着不动 | 按住**右键**不放，连续刺 5 下后松开（只做 1 次） | 重击间隔 |
| F | 拿刀，站着不动 | 按 **F** 检视，**什么都不按**，等它完全播完回到待机姿势 | 完整检视时长 |
| G | 拿刀，站着不动 | 按 **F** 检视，检视到一半按 **左键** | 检视被攻击打断后多久出刀 |
| V | 拿刀 | **先输入 `host_timescale 1` 恢复正常速度**，然后重复 A 的操作 5 次 | 慢动作和正常速度是否等比例（对照） |

录像时准星对着一面墙，枪口火光和弹孔都更容易看清。

## 四、录完之后

告诉 Claude「录好了」，并附上：
- `version` 显示的版本号
- OBS 统计里的跳帧数
- 刀是默认刀还是别的刀型；AK、Glock 有没有换皮肤（不影响时长，只做记录）

录像和 `input_log.csv` 都在 `D:\TempFiles（临时文件）\mcs\p0-5\`。最后关掉输入显示层（点它右上角的 ×）。

## 五、Claude 的分析方法（供审查参考）

**起点 = 输入显示层里对应格子变绿的第一帧**，不是「动画开始」那一帧。终点：
- 开枪项：枪口火光**或**墙上弹孔出现的第一帧，两者都看；左键格子必须在终点之前就已经亮着，否则该次作废
- 挥刀项：刀开始挥出的第一帧
- 完整动画项（K1、F）：动画回到静止待机姿势的第一帧
- 打断项（G）：从左键变绿到刀开始挥出

时长换算：游戏时间 = 帧数差 ÷ 60 × 0.1（V 项为 × 1）。

**误差与待验证事项（不在测量前预设结论）：**
- 0.1 倍速下，录像每帧约等于 1.7 ms 游戏时间。但这只是**采样间隔**，不代表测量精度；游戏渲染、显示刷新、输入显示层本身的延迟都会带来误差。输入显示层和显示器的延迟发生在真实时间里，换算成游戏时间要乘 0.1，所以慢动作能把这部分误差缩小到约 1/10
- **慢动作是否和正常速度等比例**（包括 subtick 行为）**待测量**：用 V 项与 A 项对照，若不一致，以正常速度结果为准并另行评估
- OBS 跳帧不为 0 的录像不使用
- 每项 5 次取中位数和最大偏差，写入 `data/feel/switch.csv` 与 `data/feel/knife.csv`；在 V 项验证通过前，结果都标为「待对照」
