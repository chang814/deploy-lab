# P0-5 手感测量：录制指引（给测试人）

目标：录下切枪、拔刀、检视的慢动作视频，Claude 逐帧分析出时长。**你只负责录**，分析由 Claude 来做。

预计时间：准备 10 分钟，录制 15–20 分钟。

> 红线提醒：只在**本地离线服务器**里做（「开始游戏 › 练习」或控制台开图），不要进任何官方匹配或社区服务器。录像只放在本地临时文件夹，不上传、不进仓库。

## 一、准备（只做一次）

**1. OBS 设置**
- 设置 › 视频 › 常用帧率：**60**
- 设置 › 输出 › 录像路径：`D:\TempFiles（临时文件）\mcs\p0-5\`
- 设置 › 输出 › 录像格式：`mkv` 或 `mp4` 都可以
- 来源里添加「游戏采集」或「显示器采集」，确认能看到 CS2 画面

**2. 把配置文件放进 CS2**

把仓库里的 `tools/cs2/mcs_measure.cfg` **复制**到：

```
<Steam 安装目录>\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\
```

找不到 Steam 目录：在 Steam 库里右键 CS2 › 管理 › 浏览本地文件，打开的就是 `Counter-Strike Global Offensive` 文件夹。

**3. 进本地地图**

开始游戏 › 练习 › 任选一张地图，进去后打开控制台（`~` 键；如果没开控制台，先在 设置 › 游戏 里启用开发者控制台），输入：

```
exec mcs_measure
```

看到 `mcs_measure loaded` 就成功了。再输入 `version`，**把显示的版本号拍照或复制下来**。

## 二、录制方法（每一项都一样）

1. 按 **F5** 进入慢动作（0.1 倍速）
2. OBS 开始录像
3. 按下面表格的「操作」做 **5 次**，每次之间停顿一两秒
4. OBS 停止录像，把文件**重命名成表格里的编号**（例如 `A-刀到步枪.mkv`）
5. 按 **F6** 恢复正常速度，准备下一项

**为什么要「按住左键」：** 这样第一发子弹会在「允许开火」的那一刻立刻打出来，Claude 只需要从视频里找到「动画开始」和「枪口火光出现」这两帧，就能算出时长。你不需要看按键时机，也不需要尺子。

## 三、要录的项目

| 编号 | 起始状态 | 操作 | 测的是 |
|---|---|---|---|
| A | 拿着刀 | 按 **1**，然后马上按住**左键**不放，开出第一枪后松开；按 **3** 换回刀，重复 | 刀 → 步枪，多久能开枪 |
| B | 拿着 AK | 按 **2**，马上按住左键，开枪后松开；按 **1** 换回，重复 | 步枪 → 手枪 |
| C | 拿着 USP | 按 **1**，马上按住左键，开枪后松开；按 **2** 换回，重复 | 手枪 → 步枪 |
| D | 拿着 AK | 按 **3**，马上按住左键（刀会挥出），松开；按 **1** 换回，重复 | 步枪 → 刀，多久能挥刀 |
| E | 拿着 AK，上一把是 USP | 按 **Q**，马上按住左键，开枪后松开；再按 **Q**，重复 | Q 快速切换 |
| F | 拿着刀，站着不动 | 按 **F** 检视，**什么都不按**，等它完全播完回到待机姿势；重复 | 刀的完整检视时长 |
| G | 拿着刀 | 按 **F** 检视，检视到一半按 **左键** 打断；重复 | 检视能否被攻击打断、打断后多久出刀 |

注意：
- 每次操作前先**等武器完全静止**（拔出动画播完）再做下一次
- 按住左键开第一枪就可以松开，不用打完一梭子
- 录像里的准星最好对着一面墙，枪口火光更容易看清

## 四、录完之后

告诉 Claude「录好了」，并附上：
- `version` 显示的版本号
- 你用的是哪把刀（默认刀还是别的刀型）、AK 和 USP 有没有换皮肤（不影响时长，只做记录）

录像都在 `D:\TempFiles（临时文件）\mcs\p0-5\`，Claude 会从那里读取。测完记得在控制台输入 `host_timescale 1`（或按 F6）。

## 五、Claude 的分析方法（供审查参考）

- 用 ffmpeg 抽帧；按 `docs/03-feel-measurement.md` 计算：实测时长 = 帧数差 ÷ 60 × 0.1
- 起点：当前武器开始移开的第一帧（按键在同一 tick 内生效，误差小于 1 帧）
- 终点：枪口火光或挥刀动作出现的第一帧
- 每项 5 次取中位数和最大偏差，写入 `data/feel/switch.csv` 与 `data/feel/knife.csv`
- 在 0.1 倍速、60 fps 录制下，1 帧 ≈ 1.7 ms 游戏时间，满足 G2/G3 的 7 ms 精度要求
