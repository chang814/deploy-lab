# 手感测量方案（黑盒）

目标：在**不逆向、不接触 CS2 进程**的前提下，测出切枪、拔刀、检视、攻击的时间数据。

## 环境

- CS2 **本地离线服务器**（练习模式 / 自建服务器），开 `sv_cheats 1`，**不进任何官方或 VAC 服务器**做这类测量
- 关键命令：
  - `host_timescale 0.1`：游戏时间放慢到 1/10，用普通录屏也能精确逐帧
  - `fps_max 0`，并关闭垂直同步
  - `cl_showfps 1`（可选），用于核对帧率
- 录屏：OBS，60fps 录制即可（在 0.1 倍时间尺度下相当于 600fps 的精度）

## 测量项

| 类别 | 动作 | 测什么 |
|---|---|---|
| 切枪 | 刀→步枪、步枪→手枪、手枪→步枪、Q 快切、滚轮切换 | 按键 → 武器可开火的时间；按键 → 画面中武器出现的时间 |
| 拔刀 | 任意武器→刀 | 拔刀动画总时长；可攻击时间点 |
| 检视 | 每种刀型的检视 | 检视总时长；是否分段；能被哪些操作打断 |
| 攻击 | 轻击、重击 | 出手间隔；连击节奏 |

**判定「可开火」：** 测量时持续按住开火键，记录第一发子弹出现的帧（看枪口火光 / 弹孔）。

## 流程

1. 每个动作测 **5 次**，取中位数，记录最大偏差
2. 实测时长 = 帧数差 ÷ 录屏帧率 × timescale（例：0.1 倍下 60fps 录屏差 42 帧 → 42 / 60 × 0.1 = 0.070s）
3. 写入 `data/feel/<类别>.csv`，列：`item, action, median_s, max_dev_s, samples, date, game_build, notes`
4. 社区公开数据作为交叉验证，差异 > 1 帧@144Hz 时重测

## 注意

- 游戏更新可能改变数值，每条数据都要记录 `game_build`
- 内部数据表可以用原游戏物品名作为测量参考；**产品里的刀型名称一律原创**
