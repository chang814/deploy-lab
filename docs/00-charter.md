# 立项书（Project Charter）

- 版本：v0.0.1　日期：2026-11-25
- 产品负责人 / 验收人：项目所有者（人类）
- 技术负责人：Claude

## 1. 背景与动机

CS2 玩家练枪时，切到其他练枪软件常遇到两个问题：灵敏度/视野换算不准，肌肉记忆被打乱；切枪、拔刀、检视的节奏和 CS2 不一致，「手感」不对。本项目要做一个**手感对齐**的练习工具，同时作为一次**完整真实项目流程 + 多 agent 协作**的实践。

## 2. 目标（按优先级）

| # | 目标 | 可量化验收指标 |
|---|---|---|
| G1 | 灵敏度与 CS2 1:1 | 同 DPI、同 sens 下 360° 所需鼠标位移误差 = 0（计数级精确）；FOV 对齐到 0.01° |
| G2 | 切枪手感还原 | 各类切换（主/副/刀/滚轮/Q 快切）可开火时间点与实测数据误差 ≤ 1 帧@144Hz（≈7ms） |
| G3 | 刀的手感还原 | 每种刀型的拔刀、检视、轻/重击时长与实测误差 ≤ 1 帧@144Hz；主观盲测「像」 |
| G4 | 无缝切换 | 一键只读导入 CS2 的 sensitivity / m_yaw / 分辨率相关设置 |
| G5 | 练枪可用性 | v1.0 提供基础靶场与成绩统计 |
| G6（过程目标） | 产出一套可复用的多 agent 工作流 | 每个版本有复盘记录，v1.0 时形成稳定流程文档 |

## 3. 范围

**范围内：** 第一人称视角、viewmodel 渲染、输入管线、切枪状态机、刀型手感库（数据驱动）、灵敏度导入、靶场、设置界面。

**范围外：** 联机对战、地图复刻、经济系统、皮肤系统、任何 Valve 资产。

## 4. 红线（不可违反）

1. **不使用、不入库、不分发** Valve 的任何模型、动画、音效、贴图、地图；产品名与宣传中不使用 CS / Counter-Strike 商标作为名称。
2. **不对 CS2 进程做任何内存读取、注入、hook。** 只允许读取本地 cfg 文本文件。
3. 手感数据来源：自己黑盒测量 + 社区公开数据。游戏文件中的数值仅可本地查看作为参考，**提取的文件不入库**。
4. 第三方素材必须有明确许可证（CC0 / CC-BY 等），并登记在 `assets/CREDITS.md`。

## 5. 主要风险

| 风险 | 影响 | 应对 |
|---|---|---|
| Godot 在 Windows 下鼠标输入非原始数据（含加速/取整） | G1 失败 | Phase 0 技术验证（spike）优先做；不通过则评估 GDExtension 读 Raw Input 或换引擎 |
| 帧率/输入延迟导致手感差 | G2/G3 体感差 | 关闭垂直同步、高帧率、输入在物理帧外即时处理 |
| 原创刀模型成本高 | G3 推进慢 | 先用占位模型把「节奏」做对，模型后补；优先 CC0 素材 |
| 测量误差 | 数据不可信 | 慢速时间尺度 + 高帧率录屏，同一动作测 5 次取中位数 |
| 多 agent 协作开销 > 收益 | 效率低 | 每版本复盘，必要时收敛为单家 |
